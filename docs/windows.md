# Set up a sandbox on Windows

> **Coming soon.** Windows hosts are not supported yet.

The current sandbox image runs a **macOS guest**, which requires an Apple
Silicon Mac — so there is no Windows setup guide yet. When a Windows
host/guest combination is added, this page will get the full guide.

In the meantime, the closest match is the [macOS guide](macos.md). If you also
have access to an Apple Silicon Mac, that's the guide to use.
